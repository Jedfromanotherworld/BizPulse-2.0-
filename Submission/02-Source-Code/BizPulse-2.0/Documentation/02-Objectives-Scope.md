# Objectives, scope and limitations

General objective: support daily store inventory and sales in one Android app. Specific objectives: validate role-based actions, deduct FIFO batches atomically, associate sales with cashier shifts, generate readable reports and offer offline AI explanations. Scope: one-device academic demo with owner/cashier roles, inventory, local accounts, receipts, backups and geographic supplier maps. Limitations: no multi-device sync, no banking verification, no production authentication, online map tiles and unverified physical-device performance until testing.
