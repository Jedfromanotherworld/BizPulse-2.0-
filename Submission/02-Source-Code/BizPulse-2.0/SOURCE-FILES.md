# Source map

`app/src/main/java/com/bizpulse/app`: data/db (entities/DAOs/migrations/seeder), data/repository (validation and transactions), ui/screens (Compose), ui/screens/v2 (new operations), ui/navigation (role routes), util (AI, reports, backup, images). `app/src/main/cpp`: JNI inference. `vendor/llama.cpp`: pinned inference engine. `scripts/download_model.py`: pinned model fetch and checksum. Tests: app/src/test and app/src/androidTest.
